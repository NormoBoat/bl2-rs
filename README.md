# bl2-rs

Самостоятельная реализация **Borderlands 2** на Rust с архитектурой Bevy ECS для Windows, Linux и macOS.

Цель — игра, которая ведёт себя как оригинал (логика, графика, звук, интерфейс), читает и пишет совместимые сохранения и совместима по сетевому протоколу с оригинальной игрой (сборка Steam buildid 9218157): оригинальный клиент ↔ новый хост и наоборот.

**Игровые файлы в репозитории не распространяются.** Все ресурсы (пакеты `.upk`, звуковые банки `.pck`, шейдеры и т. д.) читаются из вашей собственной легальной установки Borderlands 2. Оригинальный код при работе не исполняется.

## Состояние

Ранняя стадия: исследование форматов и поведения оригинала и слой чтения данных. Запускаемой игры пока нет.

| Крейт | Что делает |
|---|---|
| `crates/bl2-formats` | Чтение данных установки: пакеты UE3 (сжатие LZO, таблицы имён/импортов/экспортов, свойства, байткод UnrealScript), текстуры, меши, анимации, уровни, материалы, сохранения, Scaleform, Wwise (банки, Vorbis, параметры эффектов), FaceFX |
| `crates/bl2-sim` | Общая симуляция: ГСЧ и арифметика как в оригинале, FaceFX, сборка позы скелета |
| `crates/bl2-audio` | Звук: эффект Convolution Reverb Wwise (KissFFT, свёртка по разделам, микширование) |

Подробный план, доказательства, решения и текущий статус — в папке [`plan/`](plan/README.md) (начните с [`plan/status.md`](plan/status.md)).

## Сборка и проверка

Нужен Rust 1.97 или новее.

```bash
cargo build --workspace
```

```bash
cargo test --workspace
```

Тесты на данных игры помечены `#[ignore]` и требуют путь к установке в переменной `BL2_INSTALL` (что нужно каждому — в атрибуте `ignore`), например:

```bash
BL2_INSTALL="/path/to/Borderlands 2" cargo test -p bl2-audio --release --test ir_scan -- --ignored
```

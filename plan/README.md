# bl2-rs — план самостоятельной реализации Borderlands 2 на Rust + Bevy ECS

Эта папка — единственный источник правды о цели, доказательствах, решениях, задачах и состоянии проекта.
Историю чатов не используйте: всё, что нужно для продолжения, должно находиться здесь.

## Порядок начала любой рабочей сессии (обязателен для Claude и GPT/Codex)

1. Прочитать Ponytail (`.claude/skills/ponytail/SKILL.md` или `.agents/skills/ponytail/SKILL.md`, идентичны, SHA-256 `5171F4A7…3D2E`), уровень **full**. Ограничения его применения — `14-decisions.md` D-001.
2. Прочитать этот файл.
3. Прочитать `status.md` — текущее состояние, блокеры, следующий шаг.
4. Прочитать `15-handoff.md` — правила работы, обновления плана, использования REA.
5. Проверить доступность REA (`02-rea-workflow.md` §3). Если недоступен — следовать `15-handoff.md` §4.
6. Выбрать в `12-tasks.md` следующую задачу со статусом TODO, у которой все зависимости DONE и нет блокера.
7. После задачи: обновить её статус, доказательства (`03-evidence.md`), решения (`14-decisions.md`), расхождения, `status.md`.

## Структура репозитория

```
AGENTS.md, CLAUDE.md        инструкции агентам (ссылаются сюда)
.claude/skills/ponytail/    Ponytail для Claude Code (вендорная копия, закреплённый commit)
.agents/skills/ponytail/    Ponytail для Codex (та же копия)
.mcp.json                   регистрация REA MCP для Claude Code (проектная)
.codex/config.toml          регистрация REA MCP для Codex (проектная, см. T-005)
Cargo.toml, crates/          Rust-код игры (сейчас: bl2-formats)
tools/research/             исследовательские скрипты (не runtime игры)
plan/                       этот план
Borderlands 2/              локальная установка оригинала пользователя (в .gitignore, НЕ распространяется)
.tools/                     Ghidra 12.1.4, JDK 21, REA 6.7.0 (в .gitignore)
.research/                  снапшоты Ghidra, дампы, извлечённые данные (в .gitignore)
```

Код: `Cargo.toml` (workspace), `crates/bl2-formats` — чтение пакетов UE3 (T-031 DONE). Текущее состояние и следующий шаг — `status.md`.

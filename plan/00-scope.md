# 00 — Цель, ограничения, целевая сборка

## 1. Цель

Самостоятельная кроссплатформенная (Windows, Linux, macOS) реализация Borderlands 2 на Rust с Bevy ECS, которая:

- загружает оригинальные ресурсы из локальной установки пользователя (не распространяет их);
- воспроизводит игровую логику и поведение оригинала 1:1 (критерии — `10-validation.md` §2);
- воспроизводит графику, интерфейс, анимации, эффекты и звук (критерии — `10-validation.md` §3);
- совместима по сетевому протоколу с **зафиксированной сборкой** оригинала (§4): оригинальный клиент ↔ новый хост, новый клиент ↔ оригинальный хост, новые реализации между собой на трёх ОС;
- читает и пишет сохранения, совместимые с этой сборкой.

Промежуточные демонстрации (просмотрщик моделей, пустой уровень и т.п.) — этапы, а не завершение.

## 3. Технологические ограничения

- **Runtime игры**: только Rust-код проекта и Rust-библиотеки. Перед добавлением зависимости — проверка из `17-dependencies.md` §1 (нужна ли, можно ли средствами Rust/Bevy, ОС, транзитивные зависимости, лицензия, *фактическая* реализация на Rust, а не только Rust-интерфейс).
- **Инфраструктура, а не нарушение R-1**: системные API ОС, драйверы, графические API (Vulkan/Metal/DX12 через wgpu), системные аудио/ввод/сокеты. Шейдеры — на языке графического стека (WGSL); в шейдерах только графика, без игровой логики.
- **Инструменты исследования** (REA, Ghidra, JDK, Node-скрипты, Frida, Wireshark и т.п.) — не входят в runtime, язык не ограничен.
- **Не исполнять** оригинальный UnrealScript-байткод, нативный код `Borderlands2.exe` или библиотек оригинала (PhysX, Wwise, Scaleform, Bink и т.д.) в runtime. Их поведение переносится в Rust. Чтение исходных данных и инструментальная обработка скриптов для исследования допустимы (`14-decisions.md` D-005).
- **Единственное исключение — код Valve для Steam** (решение пользователя, D-010): `steam_api` заменён собственным Rust-кодом, который в рантайме загружает уже установленный у пользователя клиент Steam (`steamclient64.dll`). Есть клиент Steam — доступна игра через Steam; нет — только LAN. Ничего из Valve не распространяется и не нужно для сборки. Других исключений нет. LAN и Steam проверяются раздельно.

## 5. Не входит в объём (явно)

- Перенос универсального UE3: редактор, инструменты кукинга, Lightmass, неиспользуемые игрой рендер-пути (консольные ветки, D3D11-путь, если не используется ПК-сборкой — E-018, проверка в T-019), неиспользуемые OnlineSubsystem (Live, PS3, GameSpy, EpicStore — в установке отключены комментарием в `DefaultEngine.ini`, E-008).
- Античит VAC (`bUseVAC=true` в конфиге): поведение со стороны клиента — исследовать влияние на совместимость в T-095, но не реализовывать обход.
- Маркетинговые оверлеи (`MMOverlay`, `Launcher.exe` на .NET) — не часть игры; лаунчер не нужен для запуска (проверить, что игра запускается без него — T-017).

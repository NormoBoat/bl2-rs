# 11 — Этапы и зависимости

Этап завершён, когда все его задачи DONE с доказательствами и выполнен критерий выхода. Этапы частично параллельны; жёсткие зависимости — стрелки.

```
M0 Инфраструктура и входные данные
 ├─> M1 Исследование основ (нативы, RNG, тики, float, скрипты, шейдеры, аудио, UI, физика)
 │     └─> (питает все последующие этапы)
 └─> M2 Формат-слой (пакеты, объекты, свойства, текстуры, меши, уровни)
        ├─> M3 Ядро симуляции (Bevy-приложение, тики, акторы, коллизии, движение, replay)
        │     ├─> M4 Игровые системы (атрибуты, Behavior, оружие, лут, AI, миссии, навыки, транспорт, сохранения)
        │     └─> M6 Сеть (протокол, LAN, репликация, RPC; Steam — опционально через установленный клиент Steam, D-010)
        └─> M5 Рендер-соответствие (материалы SM3→WGSL, освещение, тени, пост, частицы, UI, видео, звук)
M8-W Приёмка Windows-реализации (T-110W)
 └─> M7 Платформы Linux/macOS (D-014: только после M8-W; до этого общий код без Windows-специфики)
       └─> M8 Полная приёмка (все ОС и вся сетевая матрица)
```

| Этап | Содержание | Критерий выхода | Задачи | Основные блокеры |
|---|---|---|---|---|
| M0 | Ponytail, REA, git, проектные инструкции, входные данные пользователя | REA работает CLI+MCP у обоих агентов; git-репозиторий; список M-пунктов закрыт или явно BLOCKED | T-001…T-006 | M-8 |
| M1 | Исследования, без которых реализация пойдёт по догадкам | Каждый вопрос R-* в `13-risks.md` переведён в VERIFIED или имеет доказанную неизвестность с обходом | T-010…T-022 | E-UNK-14 (два экземпляра) |
| M2 | `bl2-formats` | Все 2 010 пакетов и их экспорты разбираются; текстуры/меши/уровни выгружаются в отладочном просмотре | T-030…T-038 | — |
| M3 | `bl2-sim` ядро, headless, replay | Игрок ходит по любой карте с коллизией; replay-сравнение движения с записью оригинала в допуске | T-050…T-055 | T-017 (инструментирование) |
| M4 | Геймплей | Сценарии L-1…L-9 проходят | T-060…T-073 | T-012, T-013, T-016 |
| M5 | Рендер и аудиовизуальное | Кадры/звук/UI проходят `08-rendering.md` §5 | T-080…T-086, T-039…T-041, T-021a | T-017 |
| M6 | Сеть | N-1…N-4 (LAN, сначала Windows-ячейки) и N-6 (без Steam) проходят; N-5 — при запущенном клиенте Steam (D-010) | T-090…T-096 | E-UNK-14, R-16 |
| M8-W | Приёмка Windows | Критерии `10-validation.md` на Windows | T-110W | M2…M6 |
| M7 | Платформы Linux/macOS | Статусы `SCENARIOS_OK`+`NET_OK` на Linux/macOS | T-100…T-103 | D-014 (после M8-W), M-4 |
| M8 | Полная приёмка | Все критерии `10-validation.md` с доказательствами | T-110 | всё выше |

Первая демонстрация (не завершение): M2 + часть M3 — «пройтись по одной карте оригинала с исходной геометрией и коллизией». Она не меняет статус переноса.

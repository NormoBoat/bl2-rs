# 16 — Платформы: Windows, Linux, macOS

Общая реализация логики, форматов, симуляции и сети на всех ОС. Платформенные различия — в минимальном числе мест (перечислены здесь).

**Порядок работ (D-014, решение пользователя 2026-10-21)**: сначала полная реализация и приёмка на Windows (T-110W); Linux и macOS — после неё. Требование трёх ОС не ослаблено: общий код пишется без Windows-специфики уже сейчас.

## 1. Целевые конфигурации (предлагаемые; подтверждаются проверкой)

| ОС | Версии | Архитектуры | Графический бэкенд wgpu | Статус доступности для проверки |
|---|---|---|---|---|
| Windows | 10 22H2+, 11 | x86_64 (arm64 — не проверено) | DX12, Vulkan | Есть машина (Win 11 26300, RX 580) |
| Linux | дистрибутив с glibc ≥ 2.35 (Ubuntu 22.04+), X11 и Wayland | x86_64, arm64 | Vulkan | **Нет машины (M-4)** |
| macOS | 13+ | arm64 (Apple Silicon), x86_64 (Intel) | Metal | **Нет машины (M-4)** |

Минимальные версии — гипотеза, уточняется по требованиям Bevy 0.20/wgpu и реальным проверкам.

## 2. Особенности платформ (где изолированы)

| Область | Различие | Где обрабатывается |
|---|---|---|
| Файловые пути | Регистр (NTFS/APFS по умолчанию нечувствительны, ext4 — чувствителен); `\` в данных оригинала | Резолвер установки `bl2-formats` (T-033, T-101) |
| Unicode | Путь установки/профиля может содержать не-ASCII | `PathBuf` везде; тест с Unicode-путём |
| Каталоги | Сохранения, конфиги, кеш | §3, одна функция в `apps/bl2` |
| Графика | DX12/Vulkan/Metal: форматы (BCn, sRGB), лимиты | wgpu; проверка возможностей при старте с понятной ошибкой |
| Окно/ввод | Полноэкранный/оконный, HiDPI-масштабирование, захват мыши, геймпады | winit/gilrs через Bevy |
| Звук | WASAPI/ALSA-PulseAudio-PipeWire/CoreAudio | cpal через Bevy-аудио или напрямую |
| Потоки/часы | Разрешение таймеров | `std::time::Instant`; симуляция не зависит от реальных часов при replay |
| Сокеты | UDP broadcast для LAN-поиска; брандмауэр Windows; macOS — разрешение «локальная сеть» (macOS 15+) | `bl2-net`, документация установки |
| Упаковка | `.exe`/MSIX?; AppImage/tar; `.app` с подписью/нотаризацией | T-103 |

## 3. Каталоги

| Назначение | Windows | Linux | macOS |
|---|---|---|---|
| Сохранения/профиль | `%USERPROFILE%\Documents\My Games\bl2-rs\` (чтение сохранений оригинала — из их реального пути, T-017) | `$XDG_DATA_HOME/bl2-rs/` | `~/Library/Application Support/bl2-rs/` |
| Конфиг | `%APPDATA%\bl2-rs\` | `$XDG_CONFIG_HOME/bl2-rs/` | `~/Library/Preferences/bl2-rs/` |
| Кеш | `%LOCALAPPDATA%\bl2-rs\cache\` | `$XDG_CACHE_HOME/bl2-rs/` | `~/Library/Caches/bl2-rs/` |

«Документы» на Windows могут быть перенаправлены (на этой машине — в OneDrive, E-046): путь брать системным API известных папок (`FOLDERID_Documents`), а не собирать из `%USERPROFILE%`. Оригинал хранит сохранения в `<Документы>\My Games\Borderlands 2\WillowGame\SaveData\<SteamID64>\` (E-048) и синхронизирует их Steam Cloud — новая реализация не должна писать в этот каталог без явного действия пользователя (риск порчи сохранений через облако).

Совместимость сохранений с оригиналом — через импорт/экспорт по указанному пути (на Linux/macOS оригинал не запускается; файлы переносятся пользователем).

## 4. Матрица статусов (обновлять при каждой проверке)

| ОС / арх | BUILD_OK | RUN_OK | SCENARIOS_OK | NET_OK | Дата / доказательство |
|---|---|---|---|---|---|
| Windows x86_64 | только `bl2-formats` (2026-10-21) | — | — | — | E-034; приложения ещё нет |
| Windows arm64 | не проверено | | | | |
| Linux x86_64 | — | — | — | — | M-4 |
| Linux arm64 | — | — | — | — | M-4 |
| macOS arm64 | — | — | — | — | M-4 |
| macOS x86_64 | — | — | — | — | M-4 |

Правило: компиляция ≠ поддержка. `BUILD_OK` от кросс-компиляции отмечается как «кросс-сборка», а не как проверка на ОС. Непроверенные GPU (Intel/NVIDIA/AMD/Apple по каждой ОС) перечисляются отдельно в доказательстве.

## 5. Обязательные проверки на каждой ОС

Сборка, упаковка, установка, запуск; окно (оконный/полноэкранный/безрамочный, смена разрешения, HiDPI); ввод (клавиатура, мышь с захватом, геймпад); графика (кадры §5 `08-rendering.md`); звук; сохранения (путь, Unicode); сеть (LAN-обнаружение, хост/клиент, N-1); фактический состав runtime (`10-validation.md` §7).
